# Water Potability Scenario Analysis

Student ID: vingut8011

## Overview
This project uses a machine learning model to evaluate water potability and analyze how changes in water quality characteristics impact model predictions.

## Scenarios
1. Improved Water Quality
2. Environmental Contamination
3. Drought Conditions

## Sensitivity Analysis
Evaluated the impact of Sulfate, Organic Carbon, Conductivity, Hardness, Solids, Turbidity, and Trihalomethanes on water potability predictions.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Jupyter Notebook

## Results
Scenario analysis demonstrated that changes in water quality variables significantly affect predicted potability outcomes and can provide valuable insights for water treatment and environmental decision-making.
